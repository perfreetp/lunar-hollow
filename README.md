# 索道钢丝绳形态实时渲染工具

TypeScript + React + three.js 实现的架空索道钢丝绳分段悬链线实时仿真。
拖动支架、轮组或车厢时，物理求解、接触重算与管状几何更新在同一帧内完成。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npm run selftest   # 求解器物理/数值自检（30+ 断言）
npm run perf       # 2000m / 2500 环长线路帧率压力测试
npm run e2e        # Chrome CDP 交互冒烟（12 项，需先 npm run dev）
```

## 功能与需求对照

| 需求 | 实现 |
| --- | --- |
| 两端支架坐标设定 | 左侧面板数字输入 + 画布直接拖动支架头部 |
| 初始张力 5 级 | `TENSION_GEARS`（H=60–180kN），换档所有跨签名失效、接触点全量重算 |
| 单厢载荷可调 | 载荷/自重独立可调，车厢为唯一集中载荷节点 |
| 悬链线管状几何 | 解析悬链线 + 平行传输标架 + 单 BufferGeometry 单 draw call |
| 拖动同步重算 | pointer 事件内同步 `store → 求解 → 几何`，rAF 常驻渲染保证同帧呈现 |
| 分段悬链线迭代收敛 | 车厢垂向平衡 `V右−V左=P` 二分迭代，容差 0.1mm |
| 弦弧误差 < 千分之一 | 自适应布环按转角 0.03rad 加密，实测误差 ~1e-8，上界 3.75e-5 |
| 车厢移动局部重算 | 跨签名缓存，仅车厢相邻两跨重算，其余零改动 |
| 扭绞纹理沿弧长参数化 | 自定义 ShaderMaterial，UV.u=累计弧长，螺旋股脊解析生成 |
| 曲率加密防折角 | 步长=θ/κ 与 0.8m 上限取小，大曲率工况自动加密 |
| 轮组射线求交+压陷量 | 两阶段：弦投影粗筛 + 悬链线黄金分割精化（亚毫米），δ=R轮+R绳−d |
| 超阈值高亮 | 压陷量超阈值的轮组/接触点/绳体红色高亮 |
| 最多 12 组轮组 | UI 硬上限，添加按钮达上限自动禁用 |
| 张力变化全接触重算 | H 进入跨签名，换档触发全绳+全部接触点重算 |
| 跟随/环绕相机 | OrbitControls 自由环绕；跟随模式相机锁定车厢平移 |
| 导出绳形数据 | JSON 导出（参数、各跨张力/弧长、接触点、完整中线采样点） |

## 架构

```
src/
├── physics/            框架无关的纯物理层（可独立 node 运行）
│   ├── catenary.ts     单跨悬链线解析解（asinh 闭合，无需根值器）
│   ├── ropeModel.ts    多跨模型、车厢二分平衡、跨签名缓存、自适应布环
│   ├── contacts.ts     轮组接触两阶段求解（粗筛 O(n) + 黄金分割精化）
│   ├── config.ts       张力档位、物理常量、网格容差
│   └── types.ts
├── three/              渲染层
│   ├── ropeTube.ts     预分配缓冲管状几何，drawRange 控制，平行传输标架
│   ├── ropeMaterial.ts 扭绞绳股程序化 Shader（半透明 + depthWrite 排序）
│   ├── RopewayScene.ts 场景组装、对象增量同步、相机模式
│   └── dragController.ts 射线拾取 + 平面约束拖拽
├── state/store.ts      vanilla store + useSyncExternalStore，React 外驱动 3D
└── components/         面板、指标条、画布容器
```

## 关键设计决策

**同帧求解与渲染**：拖拽事件处理器只写 store，store 同步执行物理求解并更新
revision；3D 场景订阅 revision 后在同一 JS 任务内重建几何，常驻 rAF 在下一次
绘制时呈现——求解结果不会跨越两个渲染帧。React 不参与 3D 热路径，高频几何
耗时通过非响应式 `store.perf` 由指标条 4Hz 轮询。

**半透明排序**：绳材质 `transparent=true` 但 `depthWrite=true`。凸管状单网格
自遮挡由深度测试正确处理；不透明轮组先写入深度，透过绳体观察轮组时深度测试
天然给出正确遮挡，不依赖透明度排序。

**视觉半径与物理半径分离**：真实绳径 6cm 在百米级线路不足 1 像素，管状网格
按 `visualRadiusScale=4` 放大显示；压陷量等一切物理计算仍使用真实半径。

**轮组建模约定**：轮组是单向接触的托索轮，不作为绳的中间支撑节点——绳中线
在轮位处自由悬垂，轮绳关系完全由接触求解器刻画（间隙/接触/压陷三态）。

## 性能（2000m 线路，2502 环，12 轮组，`npm run perf`）

- 全绳求解 ~2.5ms，接触计算 ~1.4ms，几何更新 ~4.6ms
- 车厢拖动端到端（求解+接触+几何）最大 ~14.5ms，稳定落在 16.6ms 帧预算内
