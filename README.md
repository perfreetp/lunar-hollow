# 鼓皮张力形变台 · Drumhead Tension Lab

浏览器里的鼓皮张力与敲击形变预览工具。选鼓体与鼓皮材质、调张力档位,在三维鼓皮上点击落槌,
实时看形变与应力分布,并把整套配置导出成文件。

- **three.js** 渲染, **three-mesh-bvh** 对形变后的鼓面做射线拾取
- 形变帧全部在 **Web Worker** 中重算,主线程只负责回放
- 四个模块: 鼓体与鼓皮 / 张力与敲击 / 形变动画 / 配置导出

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 生产构建到 dist/
npm run preview
npm run typecheck
```

## 交互

- 在鼓皮上 **单击** 落槌;连续点击多个位置即可对比形变与应力差异(最多 6 处)
- 按住拖动旋转视角、滚轮缩放;拖动超过 7 px 不会误触发敲击
- `空格` 播放/暂停,`←` `→` 微调时间,`R` 重播,`Esc` 取消选中
- 张力换档 / 换材质 / 换尺寸 / 改敲击参数都会触发整场重算

## 模型

| 环节 | 做法 |
| --- | --- |
| 预张网格 | 张力 N/m → 膜面波速 `c = √(T/σ)` 与基频 `f₀ = x₀₁c / 2πa`;中央隆起随张力下降抬升;最松档位出现边缘皱褶 |
| 敲击激励 | 有限接触斑的模态耦合权重 `J_m(x ρ₀) · 2J₁(kb)/kb`,按 `1/f^0.62` 滚降 |
| 形变 | 29 阶圆膜模态(Bessel 驻波)按落点与触面加权叠加,再叠加触面凹陷;基频与高阶模态分别阻尼 |
| 应力 | 预张应力 + 波面斜率的膜应变 + 曲率的弯曲应变 + 落槌瞬间接触压力;边缘为经典应力集中;极端值做软上限 |
| 着色 | 高于静息张力的动态增量经高斯扩散后驱动色标,局部集中区直接显示为热点 |
| 时间 | 真实鼓皮振动在数百赫兹,动画按 1/34 时间尺度慢放;延音时间按真实频率与阻尼单独计算 |

数值范围为演示标定,量级与鼓皮实际工况一致(基频 ~130–290 Hz、凹陷 ~0.5–3 mm、峰值应力 ~15–100 MPa)。

## 代码结构

```
src/
  sim/        与渲染无关的模型 —— layout(网格拓扑) model(力学) types(参数) worker/protocol
  three/      DrumScene(场景、鼓面网格、BVH 拾取、着色) headGeometry(色标与几何)
  components/ 四个模块的面板与顶部/侧边读数
  store.ts    zustand 状态;useSimulation.ts 串起 Worker 重算
```
