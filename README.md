# 积木拼装咬合预览工具

基于 **React 18 + three.js + Vite** 的浏览器端积木拼装检查工具,用于在拼装前/拼装中检查凸点咬合与块间干涉。

## 四个模块

| 模块 | 位置 | 能力 |
| --- | --- | --- |
| 零件库 | 左侧栏 | 11 种常见规格(板/砖,1×1 ~ 6×12)、10 种颜色(含 3 种透明件);卡片可拖拽到拼装台,或点击放到台面中心 |
| 拼装台 | 中央画布 | 32×32 凸点台面;OrbitControls 左键旋转、滚轮缩放;拖入自动吸附最近凸点,阈值 0.1–1.0 可调 |
| 咬合检测 | 右侧栏 | 实时碰撞/咬合/悬空统计;冲突凸点红色圆盘 + 块体红色轮廓;咬合面低于设定值橙色轮廓提示 |
| 方案导出 | 右侧栏 | 序列化为 JSON(类型、颜色、网格位置、90° 朝向、咬合面/凸点、冲突关系),支持导入往返 |

## 关键设计

### 性能(120+ 块流畅)

- **空间哈希**(`src/engine/spatialHash.js`):以凸点网格为键,邻域查询 O(1),碰撞检测不做全量两两比对
- **几何体/材质缓存**(`src/three/geometry.js`):同规格积木共享一份合并几何体与材质,台面凸点用单个 `InstancedMesh`
- **增量拖拽分析**:拖动时只把当前块移出哈希做一次邻域查询,仅重算受影响块;统计回调节流到 10Hz;松手后做一次权威全量分析
- 透明块列表缓存,无透明件时逐帧排序零开销

### 碰撞与咬合(`src/engine/collision.js`,纯逻辑可单测)

- 实体干涉:水平 footprint 重叠 **且** 垂直板高区间相交
- 凸点咬合:垂直方向恰好贴合时按重叠凸点计数,区分顶面/底面
- 侧面贴合:四邻方向接触,按方向数计咬合面
- 悬空检测:z>0 的块,任一 footprint 单元正下方缺少支撑即标记

### 透明积木正确遮挡

- 透明材质 `depthWrite: false`,逐帧按到相机距离**由远及近**排序并分配递增 `renderOrder`
- 不透明块走正常深度缓冲,因此视角旋转时两类积木的遮挡关系都保持正确

### 拖拽

- 射线与积木**所在高度的水平平面**求交(动态平面常量),高层积木拖动落点不偏移
- 拖动过程持续碰撞查询并实时刷新红色高亮;未进入吸附阈值时松手自动回位
- 边界钳制保证 footprint 不越出台面;`R` 键旋转选中块,越界自动回退

## 运行

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 生产构建
npm test           # 引擎逻辑单元测试(13 项,Vitest + jsdom)
npm run test:e2e   # 端到端冒烟(需先 npm run dev;Puppeteer + 无头 Chromium,13 项)
```

端到端测试覆盖:141 块加载、干涉标记、帧率基线对比、真实指针拖拽吸附、透明深度排序、视角旋转、导出/导入位姿往返、弱咬合识别。截图输出在 `tests/e2e/shots/`。

> 无头环境使用 SwiftShader 软件渲染(约 11–18 FPS),真实 GPU 上为显示器刷新率满帧;测试以"相对空场景不塌方"为判定标准。

## 目录结构

```
src/
├── engine/          # 纯逻辑层(无 three.js 依赖,可单测)
│   ├── constants.js     # 规格、颜色、网格/世界坐标换算
│   ├── spatialHash.js   # 凸点网格空间哈希
│   ├── collision.js     # 碰撞、咬合面、悬空分析
│   ├── snapping.js      # 吸附阈值与边界钳制
│   └── serialization.js # 方案导出/导入
├── three/           # 渲染层
│   ├── geometry.js      # 几何体/材质缓存
│   └── SceneManager.js  # 场景、拾取拖拽、高亮、透明排序
├── components/      # React UI(四个模块面板)
└── App.jsx
tests/
├── engine.test.js       # 引擎单元测试
└── e2e/smoke.mjs        # 浏览器端到端冒烟
```
