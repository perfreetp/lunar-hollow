# 社区无障碍通行仿真工具

基于 **TypeScript + Svelte + three.js + three-mesh-bvh** 的轮椅通行仿真：载入带门洞、坡道和走廊的社区平面，拉伸为三维场景，求解轮椅通行路径并自动检测净宽 / 坡度 / 转弯半径超限点。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建（dist/）
npm run check      # 类型检查
npm test           # 逻辑冒烟测试（寻路 / 扫掠 / 卡点 / 转弯）
```

## 功能与操作

- **轮椅参数**：宽、长、最小转弯半径、净宽阈值，修改后自动重新求解。
- **设置起点 / 终点**：点击按钮后在平面图上点选，自动生成候选路径（栅格膨胀 A* + 视线拉直 + 门洞正交穿越 + 转弯圆弧拟合）。
- **扫掠检测**：沿路径以 0.25m 固定步长，用 three-mesh-bvh 射线在轮椅躯干高度向两侧测量净宽（取轮椅长度窗口内的最小有效净宽），并按地面高程计算坡度；净宽低于阈值、坡度陡于 1:12 或转弯半径不足的区段在三维场景中插**红色标记柱**。
- **点击标记柱**：显示该处有效净宽数值与超限原因；右侧面板卡点清单可定位到任意卡点。
- **漫游**：俯视 / 第一人称两种视角沿路径漫游（墙体、门框为真实深度遮挡，近处墙体会挡住远处标记柱）。
- **拖拽编辑**：橙色方块为门宽拖柄（拖动任一侧门垛），蓝色方块为坡道长度拖柄（拖动下坡端）；松手后路径自动重新求解并更新所有标记。
- **导出 / 载入**：导出 JSON（含平面、参数、起终点、路径与卡点清单），可再次载入恢复；也可只载入平面文件。
- **性能**：示例平面含 234 个碰撞体（墙段、门楣、柱、缘石墩），合并为单一 BVH 网格一次绘制，漫游保持流畅。

## 平面文件格式（JSON）

```jsonc
{
  "name": "示例社区平面",
  "walls": [{ "id": "w1", "x1": 0, "z1": 0, "x2": 70, "z2": 0, "thickness": 0.3, "height": 2.6 }],
  "doors": [{ "id": "gate", "wallId": "w1", "offset": 35, "width": 3.5 }],   // offset = 门中心距墙起点距离(m)
  "ramps": [{ "id": "r1", "cx": 17.5, "cz": 25.3, "dirX": 0, "dirZ": -1, "length": 6, "width": 3, "rise": 0.5 }],
  "pillars": [{ "x": 10, "z": 26.5, "w": 0.4, "d": 0.4, "h": 2.8 }],
  "floors": [{ "x1": 8, "z1": 8, "x2": 28, "z2": 22, "h": 0.5 }],             // 室内地坪高程
  "bounds": { "x1": 0, "z1": 0, "x2": 70, "z2": 50 }
}
```

- 坐标单位：米；平面为 XZ（x 东、z 南），y 向上。
- 坡道 `dir` 指向上坡端，上坡高端位于 `中心 + dir × length/2`，坡度 = `rise / length`。
- 导出的结果文件（`version: 1`）在平面字段外另含 `params / start / end / path / blockages`，载入时完整恢复。

## 实现要点

- `src/lib/geometry.ts`：平面 → 碰撞盒（门洞开洞 + 门楣），合并 `MeshBVH`；坡道 / 地坪高程函数。
- `src/lib/pathfind.ts`：栅格膨胀 A*（膨胀 = 椅宽/2）→ 门洞正交穿越点分段 → 视线拉直 → 角点清理与聚类 → 转弯圆弧拟合（含角点外移修复，仅真实墙体避障 + 坡道侧缘跌落检查）。
- `src/lib/sweep.ts`：固定步长扫掠，BVH 双侧射线测净宽，高程差分测坡度（1:12 限值，3% 浮点容差），按原因分组生成卡点。
- `src/lib/sim.ts`：三维场景、拾取 / 拖拽、漫游、标记、导入导出。
