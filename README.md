# 船闸人字门启闭机构运动仿真与干涉检查工具

基于 **three.js + manifold-3d + TypeScript + SolidJS** 的船闸人字门启闭机构三维运动仿真与实体干涉检查工具,纯前端运行,数据保存在浏览器 localStorage。

## 功能

- **三维机构模型**:人字门门叶 ×2、支铰、连杆、液压启闭机(缸筒 + 活塞杆)、含门龛的闸室墙(门龛由 manifold 布尔差集生成)、模拟障碍块。
- **运动链**:开度 θ(0–90°)→ 门叶绕支铰旋转 → 连杆铰点 C 随动 → 由 `|B−C| = 连杆长` 解算活塞杆头 B 与活塞行程(二次方程求根,含可达性判别)。
- **干涉检查**:每次开度变化后用 manifold-3d 对门体、连杆、活塞杆、缸筒与闸室墙/障碍块做实体布尔交运算,干涉区域红色高亮,列出碰撞部件对与干涉体积;铰接相连的部件对按装配关系排除。
- **关键点标注**:支铰(开度)、连杆铰点(连杆长度)、活塞杆头(活塞行程)、启闭机支座,读数随开度实时更新。
- **姿态管理**:开度档位(0/15/30/45/60/75/90°)、保存多个姿态、姿态间切换、双姿态幻影叠加对比与读数差值表。
- **导出**:姿态/对比/干涉画面截图 PNG,干涉报告 JSON。

## 四个页面

| 路由 | 页面 |
| --- | --- |
| `#/model` | 机构模型(部件清单、标注开关、读数) |
| `#/control` | 开度控制(滑块、档位、姿态保存) |
| `#/interference` | 干涉检查(碰撞对列表、高亮、报告导出) |
| `#/compare` | 姿态对比(幻影叠加、读数对比) |

## 几何约定

- 坐标系:X = 河道横向,Y = 竖直向上,Z = 河道纵向(−Z 为上游)。
- 半孔宽 12 m,门叶关闭时成拱(中缝偏上游 2 m),门叶长 √(12²+2²) ≈ 12.17 m,高 8 m。
- 连杆-门叶铰点距支铰 4 m,连杆长 3 m,机构平面在门顶上方 y = 8.5 m。
- 启闭机支座位于墙顶内缘下游侧,缸轴方向角 280°,活塞行程 0 → 1.85 m,随开度单调增加。
- 门叶端部带中缝斜切(trimByPlane),关闭时沿中缝平面接触而非重叠;门龛由墙壁布尔差集生成,全行程不穿墙。
- 闸室障碍块为演示用凸起,左门叶在约 60–75° 开度与其发生干涉。
- 支持 URL 参数:`?angle=65` 指定初始开度,`?poses=关闭:10,全开:80` 播种姿态库。
