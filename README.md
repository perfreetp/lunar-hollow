# 适老光环境渲染器

基于 TypeScript + React + three.js 的居家适老化照明设计与评估工具。

## 运行

```bash
npm install
npm run dev      # 开发服务器（默认 5173 端口）
npm run build    # 类型检查 + 生产构建
npm run preview  # 预览构建产物
```

## 功能

- **户型导入**：导入 JSON 户型文件（轮廓多边形 + 门窗位置），自动生成可旋转的三维房间（含玻璃隔断、窗玻璃、门洞）
- **三类灯具**：吸顶灯 / 壁灯 / 夜灯，面板点击后在房间内连续放置，拖动移动位置
- **灯具参数**：每类灯具 3 档色温（2700K / 4000K / 6500K）× 2 档功率
- **照度热力图**：地面与墙面逐点计算照度（点光源平方反比 + 余弦定律，吸顶灯/壁灯为余弦配光），伪彩色对数刻度叠加显示
- **点读照度**：点击地面 / 墙面 / 顶棚任意位置读取该点照度值
- **低照度标注**：照度低于 150lx 的区域自动叠加斜线纹理
- **眩光评估**：按当前相机视线方向计算统一眩光值 UGR（CIE 117 简化模型），给出 1~5 级眩光等级
- **昼夜预设**：白天 / 夜间两种环境光；夜间模式自动压低环境光、增强夜灯发光并突出夜灯→门口的引导路径
- **透明排序**：半透明灯罩、玻璃隔断、热力叠加层分层 renderOrder + 关闭深度写入，无穿透伪影
- **同步重算**：拖动灯具或修改参数时，热力图（拖动中粗网格、松手细网格）、UGR 等级、能耗估算三处同步更新
- **性能**：灯具共享几何体与材质，40+ 灯具时拖动流畅
- **导出 / 导入**：当前方案（户型 + 灯具清单 + 昼夜模式）导出为 JSON 文件，可重新导入还原

## 户型文件格式

```json
{
  "name": "我的户型",
  "height": 2.7,
  "outline": [[0, 0], [6.4, 0], [6.4, 3.2], [4.2, 3.2], [4.2, 5.2], [0, 5.2]],
  "doors": [{ "wall": 4, "offset": 1.6, "width": 0.9, "height": 2.1 }],
  "windows": [{ "wall": 0, "offset": 2.2, "width": 1.8, "sill": 0.9, "height": 1.5 }],
  "glassPartitions": [{ "from": [3.0, 1.7], "to": [5.2, 1.7], "height": 2.2 }]
}
```

- `outline`：俯视多边形顶点 `[x, z]`（米），顺逆时针均可（自动规范）
- `wall`：门窗所在墙的索引，即 `outline` 第几条边（从 0 开始）
- `offset`：门窗距该墙起点的距离（米）

导入时自动识别文件类型：完整方案文件（含灯具清单）或纯户型文件（仅轮廓与门窗）。

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键拖动 | 旋转视角 |
| 滚轮 / 右键拖动 | 缩放 / 平移 |
| 点击面板灯具按钮 → 点击房间 | 放置灯具（壁灯点墙面，其余点地面），Esc 结束 |
| 拖动灯具 | 移动位置（壁灯自动吸附墙面） |
| 点击灯具 | 选中，可调色温 / 功率 / 删除（Delete 键） |
| 点击地面 / 墙面 | 读取该点照度 |

## 计算模型说明

- 照度：`E = Σ I(θ)·cos(入射角)/d² + 环境基准`，吸顶灯/壁灯为半球余弦配光，夜灯全向
- UGR：`8·log10(0.25/Lb · Σ L²·ω/p²)`，背景亮度由地面平均照度推算，观察点为当前相机视线
- 能耗：各类灯具按典型日均点亮时长（吸顶 5h / 壁灯 3h / 夜灯 9h）估算
