# 船闸船舶过闸轨迹仿真工具

基于 TypeScript + Vue 3 + Babylon.js(WebGPU 引擎,不支持时自动降级 WebGL2)的船闸过闸仿真。在三维闸室场景中布置上下游引航道与人字闸门,支持最多 20 艘船排队依次过闸,全过程记录轨迹并可任意时刻回放。

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 生产构建 → dist/
npm run verify     # 无头验证仿真内核(无需浏览器)
npm run typecheck  # 类型检查
```

## 四个页面

| 页面 | 功能 |
|---|---|
| 场景与船舶配置 | 闸室/引航道/水位/闸门参数,船舶增删与船长、船宽、进闸顺序、初始速度、吃水设置,3D 实时预览,配置校验 |
| 过闸流程控制 | 一键运行仿真,播放/暂停/0.5–8× 调速,实时阶段、水位、闸门角度、逐船状态与事件日志 |
| 时间轴回放 | 拖动时间轴回看任意时刻的船舶位置、闸门角度、水位高度,事件标记(阶段/碰撞) |
| 仿真结果导出 | 概要统计、各船过闸时间、事件日志,导出轨迹 JSON 文件 |

## 仿真模型

- **流程**:每闸次 = 水位准备 → 开进闸门 → 依次进闸停靠 → 关进闸门 → 水位调整 → 开出闸门 → 依次出闸 → 关出闸门,自动划分多闸次(按闸室可用长度贪心装箱)。
- **闸门**:按角度档位步进(°/档、s/档 可配),人字门两扇联动。
- **水位**:按升降速率(m/s)变化;船舶吃水随水位浮动(船底 = 水面 − 吃水)。
- **碰撞检测**:船-船(AABB + 跟船限速)、船-闸室墙/导航墙、船-闸门(未全开禁行);碰撞时减速/停车并在事件日志与导出数据中记录。
- **回放**:仿真以 0.1s 步长预计算、0.5s 间隔记录轨迹帧(Float32Array),回放零计算量线性插值,20 艘船渲染轻松保持 50 FPS 以上。

## 数据存储

- 场景与船舶配置:`localStorage`(自动保存,刷新恢复)
- 最近一次仿真轨迹:`IndexedDB`(Float32Array 二进制,刷新后可继续回放)
- 导出:JSON 文件(配置、船舶、闸次、事件、全部轨迹帧)

## 目录结构

```
src/
  sim/        仿真内核(纯 TS,无 DOM 依赖,可无头测试)
    types.ts      数据模型
    simulate.ts   仿真器 + 采样器 + 校验
  scene/      Babylon.js 场景(WebGPU 优先)
  pages/      四个页面
  components/ SceneView(共享 3D 视图)
  store.ts    全局状态与持久化
verify-sim.mjs  仿真内核无头验证脚本
```
