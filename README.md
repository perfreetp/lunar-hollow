# 赛道三维漫游工具

基于 **TypeScript + Svelte 5 + Babylon.js** 的赛道三维漫游应用。沿闭合赛道中心线程序化生成路面与红白路肩曲面,支持 8 路段跳转、300m 环域流式分块(三级 LOD + 占位衔接)、自动巡航/自由飞行、实例化护栏看台、轮胎痕迹贴花累积、小地图点击跳转与相机姿态导出。

## 快速开始

```bash
npm install
npm run dev          # http://localhost:5173
```

其他命令:

```bash
npm run build        # 生产构建
npm run typecheck    # tsc 类型检查
npm run check        # svelte-check(Svelte 模板检查)
npm run test:logic   # 纯逻辑冒烟测试(中心线/弧长/标架/路段)
npm run test:e2e     # 浏览器端到端(需先启动 dev server,使用本机 Chrome)
npm run test:deep    # LOD/实例化/UV 弧长/占位几何深度验证
```

## 页面结构(按"进入赛道 → 漫游 → 导出"流程组织)

1. **赛道加载与路段跳转** — 进入赛道、赛道总长/分块信息、8 个路段跳转按钮、分块加载状态
2. **漫游相机与速度控制** — 巡航/飞行切换、5 档速度、实时速度/弧长/朝向/里程/FPS
3. **路面路肩材质与轮胎痕迹** — 材质映射说明、胎痕强度进度条、清除胎痕
4. **小地图与位置导出** — 赛道俯视图(分块 LOD 着色、路段编号、朝向三角),点击任意位置跳转,一键导出姿态 JSON

## 核心架构

```
src/
├── lib/
│   ├── track/
│   │   ├── centerline.ts   # 闭合 Catmull-Rom → 弧长重采样 → 平行移动标架(RMF)
│   │   ├── geometry.ts     # 带状网格构建器,UV.u 烘焙为弧长(米);沥青/路肩贴图
│   │   ├── scenery.ts      # 分块流式管理:300m 环域、占位盒、三级 LOD、InstancedMesh
│   │   ├── tireMarks.ts    # 轮胎痕迹贴花 ribbon + DynamicTexture,按里程累积加深
│   │   ├── camera.ts       # 巡航/自由飞行相机,5 档速度,姿态导出
│   │   └── engine.ts       # 引擎总装与渲染循环
│   └── state/roam.ts       # RoamState 类型 + Svelte store(引擎写、UI 订阅)
├── components/             # 四个 Svelte 面板
└── App.svelte              # 流程编排与 HUD 布局
scripts/                    # 逻辑/端到端/深度三套测试
```

### 关键设计

- **弧长均匀映射,条纹不拉伸**:中心线先做 Catmull-Rom 细分,再按累计弧长重采样为 2m 等距标架;所有带状网格(路面、双侧路肩、胎痕层)的 `UV.u` 直接写入累计弧长(米),贴图 `uScale` 以"每米重复次数"配置。路肩红/白各 1m,因此条纹宽度在直道与弯道完全一致(深度测试实测相邻行 u 增量标准差 ≈ 1e-13)。
- **稳定标架**:采用平行移动标架(Rotation-Minimizing Frame)而非 Frenet 标架,直道上不会出现法线翻转。
- **流式分块**:赛道按 50m 一块切分(共 48 块),视点 300m 环域内的分块进入异步加载队列(并发 2、模拟 220–820ms 网络延迟);加载期间显示半透明占位盒覆盖该段,杜绝空洞;超出环域即卸载。
- **三级 LOD**:LOD 按距离 120m / 220m 切换,只做 `InstancedMesh` 显隐(tier 0/1/2),不重建几何;远处仅保留护栏横梁、看台主体、树干等低模部件。
- **实例化批量渲染**:护栏(横梁+密/疏立柱)、看台(主体/座位排/细排)、树木(树干/树冠/细枝)共 9 个源网格,运行时约 850+ 个 `InstancedMesh`,源网格本身隐藏只作模板。
- **轮胎痕迹**:独立半透明 ribbon 抬升 0.035m 防 z-fighting,强度按 1024 栅格沿弧长累积,双轮迹绘制到 `DynamicTexture`,10Hz 节流重绘;仅巡航贴地时沉积,自由飞行不留痕。
- **小地图**:Canvas 2D 等比投影,分块按 LOD/加载状态着色,白色三角显示位置与朝向;点击坐标反解最近弧长后跳转,相机与分块加载状态联动刷新。
- **导出文件**:JSON 含相机世界坐标、朝向向量、弧长、路段、模式、档位、环视角、里程以及全部分块的 state/LOD 快照。

## 验证情况

- `test:logic`:弧长等距性、标架正交性、环形回绕、8 路段边界、环形距离、速度档位
- `test:e2e`(真实 Chrome + WebGL2,20 项):赛道初始化、HUD 四模块、路段跳转、模式切换、5 档速度、胎痕累积、小地图跳转、JSON 导出内容
- `test:deep`(11 项):三级 LOD 实际分布、环域外卸载、路肩 UV 弧长均匀性、858 个实例 / 9 个源网格、占位盒出现与移除时序
