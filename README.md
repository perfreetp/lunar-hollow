# RC 悬挂姿态实验室 · Suspension Attitude Lab

在浏览器里装配遥控车前悬挂连杆，并实时预览摆臂运动下的轮毂姿态。
Vue 3 + TypeScript + Babylon.js，整套运动学、间隙检测与遮挡判断都在 CPU 上
用解析几何求解，因此每一帧的结果都是确定的、可单元测试的。

```
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5173
npm run build      # 生产构建 → dist/
npm run verify     # 类型检查 + 单元测试 + 无头浏览器冒烟测试
```

## 四个模块

| 模块 | 能力 |
| --- | --- |
| 01 连杆装配 | 从零件库把下摆臂 / 上摆臂 / 转向节 / 拉杆拖入画面，指针靠近轴位时按屏幕像素吸附；落点换算成 mm 偏差，超过阈值标红并拒绝安装（可「强制固定」保留）。拆卸上层零件会连带拆掉依赖它的零件。 |
| 02 行程调节 | 设定上/下行程、预压量与齿条行程；预压会被折算成静态抬升并占用上行程。「连杆尺寸」中任意一项改动都会重建整条链。附外倾/前束/半轮距/避震长度随行程的曲线。 |
| 03 姿态预览 | 拖动轮毂或下摆臂摆臂，每帧重算整条连杆链。按相机做射线遮挡判断并统计各层被遮挡比例；轮毂与车架、避震器、转向节之间做 SDF 间隙检测，穿插处标红高亮。 |
| 04 配置导出 | 把连杆尺寸、连接关系、行程参数序列化为带签名的 JSON；可下载 / 复制 / 生成分享串，也能导入回来并给出校验提示。 |

## 运动学

每个动画帧都从「下摆臂角」出发重新解算，没有增量积分，因此不会漂移：

1. **下摆球头 LBJ** = 下摆臂枢轴 + 臂长 · `(cosθ, −sinθ)`，θ 由轮跳行程二分反解
   （`thetaForTravel`，两项联动修正把轮心高度误差压到 1e-4 mm）。
2. **上摆球头 UBJ** = 上摆臂圆 ∩ 主销球。两解中按「主销倾角最接近设计姿态」取一支，
   这是几何判据而不是「离上一帧最近」——后者会在极限行程锁到镜像解，表现为外倾角
   突然跳到 −30° 之类的假象。
3. **转向节姿态** = 把设计主销方向最小旋转到当前主销方向。
4. **转向角** = 拉杆圆 ∩ 球（转向臂绕主销扫出的圆 ∩ 齿条球头球），两解中取离设计
   姿态更近的一支，平局时用上一帧的连续性裁决。
5. 轮心、轮轴、外倾、前束、磨胎半径、避震长度/压缩量全部由这一步派生。

`src/core/kinematics.ts` 是纯函数模块，测试见 `src/tests/kinematics.test.ts`。

## 间隙与遮挡

* 轮胎按真实圆角圆柱采样成 ~600 个表面点（含侧壁与胎肩），逐个对车架 OBB 与避震
  胶囊做 SDF 求值，因此平直面无法从采样缝里「漏过去」。转向节另外补一组探针。
* 遮挡用射线：轮毂与避震表面样本各向相机投射，被其它层挡住即标记为隐藏，得到每层
  的可见比例，可在预览面板查看，也能在场景里打开「遮挡探针」直接看到红/绿点。
* 间隙与遮挡都在 `src/core/collision.ts`，有独立的单元测试覆盖射线、SDF 与报告形状。

## 层级与不闪烁

三层（车架 / 避震器 / 轮毂）按用户可调的顺序映射到 Babylon 的
`renderingGroupId`，并给每层材质设置单调变化的 `zOffset`：

* 渲染组只决定**绘制顺序**，深度缓冲在各组之间**共用**
  （`setRenderingAutoClearDepthStencil(g, false, false, false)`），
  所以遮挡关系始终由真实几何决定，不会因为「轮毂画在后面」就被看穿。
* 共面几何靠 `zOffset` 的多边形偏移决定谁在前，避免 z-fighting 闪烁。
* 所有解算的分支选择都是连续的（见上），拖动时不会出现姿态跳变或正负翻转；
  冒烟测试会实际拖动并断言「无跳变、无符号翻转、无非有限值」。

## 坐标系与约定

右前角、右手系、单位 mm：`+X` 向外，`+Y` 向上，`+Z` 向前。摆臂角 θ 以
`(cosθ, −sinθ)` 方向为正，即 θ 增大时摆臂向下外摆（车轮下坠）。预览时轮胎保持
在地面，车身随行程上下移动（`setBodyOffset`），与真实悬架一致。
