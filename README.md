# 发条齿轮预演工作室 Clockwork Studio

基于 **Svelte 4 + three.js + Vite** 的发条玩具运动预演工具：在浏览器里装配齿轮组、
配置传动关系、预览发条驱动下的整链同步转动，并把布局与传动关系导出为可分享的配置文件。

## 启动

```bash
npm install
npm run dev      # 开发，默认 http://localhost:5173
npm test         # 传动数学单元测试（node:test，10 项）
npm run build    # 生产构建到 dist/
```

## 四大模块

| 模块 | 能力 |
| --- | --- |
| ① 齿轮装配 | 从齿轮库（8/10/12/16/20/24/32 齿）拖入画布，网格吸附放置到轴位；相邻齿轮中心距满足 `r₁+r₂` 时自动啮合；啮合间隙超过 ±0.18 阈值时底部实时告警 |
| ② 传动配置 | 指定主动轮（发条轮）与从动轮；按齿数比 `ω₂/ω₁ = −z₁/z₂` 计算有符号转速；修改任一齿轮齿数后，整条传动链的转速、方向、相位在同一次提交内联动重算 |
| ③ 运动播放 | 发条圈数 0–20 圈可调；播放时所有齿轮按传动关系同帧同步转动，转向交替；支持暂停/复位/进度拖动/0.5–4× 速率 |
| ④ 配置导出 | 齿轮布局、齿数、主动轮、全部啮合传动关系序列化为带 schema 的 JSON，支持下载、复制、文件导入并校验还原 |

## 无穿透与渲染正确性如何保证

1. **滚动约束不变量**（`src/lib/gearMath.js`）
   外啮合满足 `zⱼ·θⱼ + zᵢ·θᵢ ≡ C (mod 2π)`。建边时在接触方向把从动轮齿槽对准主动轮最近齿，
   播放中按 `ωⱼ = −(zᵢ/zⱼ)·ωᵢ` 传动，接触点齿/槽相对相位恒定——任意时刻都是齿入槽而非齿撞齿。
   单测 `滚动约束不变量` 与 `接触点对准` 在 0–20 圈多个转角下验证残差 < 1e-9。
2. **几何侧隙/顶隙**（`src/lib/gearGeometry.js`）
   梯形齿齿顶角宽 40%、齿槽角宽 48%，配对齿两侧预留均匀侧隙；齿根圆低于啮合深度预留顶隙，
   从几何上消除刮擦。
3. **整链同帧更新**（`src/lib/store.js` + `GearScene._tick`）
   任何结构变更走同步 `commit()` → `recompute()` 一次性完成啮合判定、BFS 相位/速比传播后才替换快照；
   渲染帧只从最新快照读取角度。因此播放中调整传动比，下一帧前全链已重算完毕。
4. **前后遮挡与轴心穿插**
   啮合齿轮同层、几何重叠（非啮合）齿轮由分量图着色自动分配不同深度层（z 轴错开 1.7 单位，大于齿厚），
   配合贯穿各层的轴杆与凸出轮毂表达轴心关系，重叠件不再错误穿插。

## 目录结构

```
src/
  lib/
    gearMath.js       纯函数核心：啮合判定、滚动约束、BFS 全链重算、深度分层
    gearGeometry.js   齿轮/轮毂/轴杆 three.js 几何（梯形齿 + 侧隙）
    store.js          快照式状态机、播放状态、序列化/导入
    GearScene.js      three.js 场景、拾取拖拽、每帧整链角度同步
  components/         齿轮库、传动面板、播放条、告警列表、导出面板
tests/gearMath.test.js  数学不变量与重算单测
scripts/                CDP 无头浏览器验证脚本（截图 + 交互断言）
docs/                   验证截图与交互断言结果
```

## 调试钩子（仅带 URL 参数时启用，不影响正常使用）

- `?progress=0.5` 预置播放进度，便于复现任意相位
- `?capture=1` 开启 `preserveDrawingBuffer` 并在 `window` 暴露场景与 store，供自动化验证

## 关键参数

模数 m=1，网格 1 格 = 0.5 世界单位，故两轮理想啮合的网格中心距恰为 `z₁+z₂`；
啮合容差 ±0.18，接近提示带宽 0.65，建议深度层数 ≤ 4。
