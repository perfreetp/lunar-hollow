# 卫浴扶手布置渲染器

基于 **TypeScript + SolidJS + three.js + postprocessing** 的卫生间扶手布置工具。

## 运行

```bash
npm install
npm run dev      # 开发服务器（默认 http://localhost:5173）
npm run build    # 生产构建到 dist/
npm run check    # TypeScript 类型检查
```

## 功能

- **场景载入**：内置默认浴室（四面墙 + 地面 + 洁具）；也可通过「载入模型 (GLB)」导入卫生间网格，自动识别可安装墙面（|法线 y| ≤ 0.45）与地面，并以蓝色半透明面标示可安装区域。
- **三种扶手**：一字型 / L 型（可水平翻转）/ 折叠型（0–90° 上翻）。从左侧扶手库**拖到墙面**即可放置，绿色预览实时跟随。
- **墙面贴合**：扶手自动对齐墙面法线，沿墙拖动时约束在墙面范围内；离地高度 30–150cm 可调（拖动或滑杆）。
- **镜面预览**：切换到镜面模式后相机自动转到浴室镜前，Reflector 实时渲染反射画面；**在镜中同样可以拖动扶手**（拾取射线关于镜面反射后再求交）。
- **半透明防闪烁**：扶手为半透明金属材质（depthWrite 关闭），每帧按离相机距离远→近赋 renderOrder，转角处两根扶手交叠时绘制顺序稳定不闪烁。
- **尺寸标注**：每根扶手悬浮显示长度与离地高度；长度 40–120cm 可调，调节时端点与墙面接触点（法兰/支撑腿）同步移动。
- **轮廓描边**：postprocessing 的 OutlineEffect 高亮扶手与墙面的边界，可在顶栏开关。
- **导出 / 导入**：导出 JSON 文件，包含相机视角、视图模式、描边开关及每根扶手的墙面坐标（u、离地高度）、法线、长度、折叠角度；重新导入后还原相同视角与布置（墙面按名称或"贴合点+法线"反查）。

## 操作

| 操作 | 说明 |
| --- | --- |
| 拖左侧面板到墙面 | 放置扶手 |
| 拖动扶手 | 沿墙移动（水平位置 + 离地高度） |
| 点击扶手 | 选中（右侧出现参数面板） |
| Delete / Backspace | 删除选中扶手 |
| Esc | 取消拖放 |
| 鼠标拖动 / 滚轮 | 旋转 / 缩放视角 |

## 代码结构

```
src/
  App.tsx            SolidJS 界面（工具栏、扶手库、参数面板）
  state.ts           Solid store（视图模式、描边、选中、扶手清单）
  types.ts           BarSpec / LayoutFile 序列化类型
  three/
    engine.ts        渲染引擎：拾取（含镜面反射射线）、拖拽、透明排序、导入导出
    bars.ts          三种扶手的网格构建与长度/角度调节
    world.ts         默认浴室、墙面识别、可安装区域标示、浴室镜
```
